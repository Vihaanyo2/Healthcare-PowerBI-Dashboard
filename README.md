Healthcare Power BI Dashboard

## Project Overview

This project demonstrates a complete Healthcare Analytics Dashboard built using Microsoft Power BI.

The dashboard provides insights into patient appointments, billing, doctors, treatments, and hospital performance using interactive visualizations.

---

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- CSV Dataset

---

## Features

- KPI Cards
- Slicers
- Drill Through
- Bookmarks
- Navigation Buttons
- Dynamic Titles
- Data Cleaning
- Merge Queries
- Append Queries
- Date Table
- Relationships

---

## KPIs

- Total Patients
- Total Doctors
- Total Revenue
- Total Appointments
- Average Billing
- Completed Treatments

---

## Dashboard Pages

### Overview

Shows overall hospital performance.

### Doctor Analysis

Performance by doctor.

### Patient Analysis

Patient demographics and appointments.

### Billing Analysis

Revenue and billing insights.
